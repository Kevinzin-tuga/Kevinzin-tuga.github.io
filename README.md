# Kevinzin Portfolio

Static portfolio using HTML, CSS and JavaScript. The layout follows the section order and core widgets observed on RibeiroMD, with Kevinzin content and the aqua accent `#03FCD7`.

Files: `index.html`, `style.css`, `script.js`, `stats.html`.

Publish the files in the repository root on branch `main`, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/(root)`.

Notes: GitHub profile counters are loaded from the public GitHub API. Contribution totals and project-download metrics are intentionally not fabricated; connect a contribution API and real project data sources to populate them.
